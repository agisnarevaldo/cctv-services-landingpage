# Cara Monitoring CCTV dari HP: Setup Remote Viewing dalam 5 Menit

Salah satu keunggulan CCTV modern adalah kemampuan **remote viewing** - memantau rekaman dari mana saja melalui smartphone. Artikel ini akan memandu Anda setup remote viewing dengan mudah.

## Aplikasi Remote Viewing Populer

Setiap brand CCTV memiliki aplikasi resmi:

| Brand | Aplikasi | Platform |
|-------|----------|----------|
| Hikvision | **Hik-Connect** | iOS, Android |
| Dahua | **DMSS** / gDMSS | iOS, Android |
| Ezviz | **EZVIZ** | iOS, Android |
| Imou | **Imou** | iOS, Android |
| Hilook | **Hik-Connect** | iOS, Android |

## Syarat Remote Viewing

Sebelum setup, pastikan:
1. ✅ DVR/NVR sudah terhubung ke internet (kabel LAN)
2. ✅ Router memiliki koneksi internet stabil
3. ✅ Smartphone terinstall aplikasi yang sesuai
4. ✅ Akun sudah terdaftar di aplikasi

## Panduan Setup Hik-Connect (Hikvision)

### Langkah 1: Persiapan DVR/NVR

1. Masuk ke menu DVR melalui monitor
2. Buka **Configuration → Network → Platform Access**
3. Aktifkan (Enable) Hik-Connect
4. Catat **Verification Code** (6 digit)

### Langkah 2: Install dan Login Aplikasi

1. Download **Hik-Connect** dari Play Store/App Store
2. Buat akun baru atau login
3. Masukkan nomor HP untuk verifikasi

### Langkah 3: Tambahkan Perangkat

1. Tap tombol **"+"** di pojok kanan atas
2. Pilih **Scan QR Code** (lebih mudah)
3. Arahkan kamera ke QR Code di DVR
4. Masukkan Verification Code
5. Beri nama perangkat (misal: "CCTV Rumah")
6. Selesai! Kamera langsung tampil

### Langkah 4: Konfigurasi Tambahan

- **Notifikasi**: Aktifkan push notification untuk motion detection
- **Playback**: Putar rekaman langsung dari HP
- **Screenshot**: Ambil foto dari video live
- **Share**: Bagikan akses ke anggota keluarga

## Panduan Setup DMSS (Dahua)

### Langkah 1: Persiapan NVR

1. Buka menu NVR → **Network → P2P**
2. Pastikan status **Online**
3. Catat **SN** (Serial Number) perangkat

### Langkah 2: Setup di Aplikasi

1. Download **DMSS** atau **gDMSS Plus**
2. Buat akun dan login
3. Tap **"+"** → **Scan QR Code** atau **Manual Add**
4. Masukkan SN perangkat
5. Input username dan password DVR
6. Simpan dan akses

## Tips Agar Remote Viewing Lancar

### Kecepatan Internet

| Kualitas Stream | Upload Speed Minimal |
|-----------------|---------------------|
| Sub-stream (SD) | 512 Kbps |
| Main-stream (HD) | 2 Mbps |
| 4 kamera HD | 4-6 Mbps |

### Optimasi Jaringan

1. **Gunakan sub-stream** untuk viewing, main-stream untuk recording
2. **Prioritaskan DVR** di pengaturan QoS router
3. **Restart router** berkala untuk menjaga koneksi stabil
4. **Upgrade paket internet** jika sering buffering

### Keamanan

1. ✅ Ganti password default DVR
2. ✅ Aktifkan 2FA di aplikasi
3. ✅ Jangan share password sembarangan
4. ✅ Update firmware DVR secara berkala

## Troubleshooting Umum

| Masalah | Solusi |
|---------|--------|
| Tidak bisa connect | Cek koneksi internet DVR |
| Buffering terus | Turunkan kualitas stream |
| Offline di aplikasi | Restart DVR dan router |
| Lupa password | Reset via email atau teknisi |
